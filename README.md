# CodeOrbit Simple Calculator

## Project Description
This is a simple calculator developed using Python.

## Features
- Addition
- Subtraction
- Multiplication
- Division
- Zero Division Handling
- Invalid Input Handling

## Technology Used
- Python 3.14.5
- Visual Studio Code

## How to Run
1. Open VS Code.
2. Open calculator.py.
3. Run the program.
4. Enter two numbers.
5. Choose an operation.
